# openscad-iterate (Claude Code skill)

Render-and-verify workflow for parametric OpenSCAD / 3D-print projects:
view selector, render and STL export scripts, cross-sections, print
orientation, slicer checks. `SKILL.md` is the skill itself, and
`references/` holds the templates.

Install locally: `git clone https://github.com/candas-agent/openscad-iterate ~/.claude/skills/openscad-iterate`.
In Claude Code cloud sessions, each project's `.claude/cloud-setup.sh` clones it there at session start.
